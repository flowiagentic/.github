# flowiagentic/.github

Default community health files for every repository in the flowiagentic organization. Today it holds only the issue templates:

- **Feature (parent issue)** — opened in `flowi-architecture`, with one sub-issue per layer repository.
- **Bug or layer task** — opened in the repository whose code changes.

Both add the issue to the organization project **Flowi**. A repository that has its own `.github/ISSUE_TEMPLATE/` uses its own templates instead.
